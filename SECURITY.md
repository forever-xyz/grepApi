# Security Policy / 安全策略

## Supported Versions / 支持版本

Security fixes are applied to the latest released version of Grep API.

安全修复将应用于 Grep API 的最新发布版本。

## Reporting a Vulnerability / 报告安全漏洞

Please do not report security vulnerabilities in a public GitHub issue.

请不要在公开 GitHub Issue 中披露安全漏洞。

Send a report to `ikunzp520@gmail.com` with:

- A description of the vulnerability.
- Reproduction steps or a minimal proof of concept.
- Affected IntelliJ IDEA and plugin versions.
- The expected security impact.

请将漏洞描述、复现步骤、受影响版本和预期影响发送至 `ikunzp520@gmail.com`。

Please allow reasonable time for investigation and remediation before public disclosure.

在公开披露前，请为问题调查和修复预留合理时间。
