# Code of Conduct / 行为准则

Grep API is committed to a friendly, inclusive, and professional community.

Grep API 致力于建设友好、包容、专业的开源社区。

## Expected Behavior / 期望行为

- Be respectful and constructive.
- Discuss ideas and code rather than attacking people.
- Welcome contributors with different backgrounds and experience levels.
- Protect private information and report security issues privately.
- Accept maintainers' decisions made to protect the project and community.

- 保持尊重并提供建设性意见。
- 讨论观点和代码，不进行人身攻击。
- 欢迎不同背景和经验水平的贡献者。
- 保护隐私，安全问题应私下报告。
- 尊重维护者为保护项目和社区作出的决定。

## Unacceptable Behavior / 不可接受的行为

Harassment, discrimination, threats, deliberate disruption, publication of private information, spam, and abusive language are not accepted.

本项目不接受骚扰、歧视、威胁、蓄意破坏、泄露隐私、垃圾信息和侮辱性言论。

## Enforcement / 执行

Report conduct concerns privately to `ikunzp520@gmail.com`. Maintainers may edit or remove content, reject contributions, or temporarily or permanently restrict participation when necessary.

请将行为问题私下发送至 `ikunzp520@gmail.com`。必要时，维护者可以编辑或删除内容、拒绝贡献，或临时、永久限制参与。
