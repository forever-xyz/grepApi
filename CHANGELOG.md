# Changelog

All notable changes to Grep API are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [0.0.1] - 2026-07-16

### Added

- Search Spring MVC and Spring WebFlux annotation-based endpoints.
- Search by URL, path, HTTP method, curl command, Controller, Java method, or module.
- Strict contiguous matching for URL-path input.
- GET, POST, PUT, DELETE, PATCH, HEAD, and OPTIONS filtering.
- Direct navigation to the matching Mapping declaration.
- Configurable gateway and service prefixes.
- Incremental route caching and result limiting for low memory usage.
- Chinese user interface, plugin icons, and `Ctrl + Alt + /` shortcut.
- Configurable blue, green, orange, or purple background highlighting for matched path text.
- Compatibility baseline for IntelliJ IDEA 2024.1 through 2026.x.
